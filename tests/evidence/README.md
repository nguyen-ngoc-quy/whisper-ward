# Test Evidence & Visual Logs

This directory stores manual test walkthroughs, visual feel validation, and playtest sign-off logs.

## Structure
- `screenshots/` — Visual proof of HUD layout, lighting, and camera framing.
- `sign-offs/` — Lead sign-off notes for non-automated stories (Feel, Art, UX).
- `walkthroughs/` — Step-by-step verification reports for UI and menu interactions.
